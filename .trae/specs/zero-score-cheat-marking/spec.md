# 阅卷中心作弊试卷零分快速处理 Spec

## Why
当前阅卷中心（blog-admin MarkingCenter.vue）对标记为作弊嫌疑（cheatFlag=1）的答卷仍要求管理员逐题评分后才能提交，处理流程繁琐；作弊答卷应默认主观题零分，管理员一键提交即可。

## What Changes
- 作弊答卷（detail.cheatFlag === 1）选中时，所有主观题评分表单自动预填 0 分，评语预填"作弊嫌疑，主观题记零分"（可修改）。
- 作弊答卷的"未评分不可提交"校验自然满足（分数已预填），管理员可直接点"提交评分"发布。
- 作弊答卷在批改面板顶部信息栏增加提示（如警示条：该答卷存在作弊嫌疑，主观题已默认零分）。
- 管理员仍可手动修改预填的分数/评语（保留人工复核能力）。

## Impact
- Affected specs: 无
- Affected code: `blog-admin/src/views/MarkingCenter.vue`（仅前端改动，无后端/接口变更）

## ADDED Requirements

### Requirement: 作弊答卷默认零分
阅卷中心 SHALL 在管理员选中 cheatFlag=1 的答卷时，将全部主观题评分预填为 0 分并附默认评语，使管理员无需逐题打分即可直接提交发布成绩。

#### Scenario: 选中作弊答卷
- **WHEN** 管理员点击一条带"作弊嫌疑"标记的待批答卷
- **THEN** 所有主观题评分为 0、评语为"作弊嫌疑，主观题记零分"，且信息栏显示作弊警示
- **AND** 管理员可直接点击"提交评分"完成发布，无需逐题打分

#### Scenario: 正常答卷不受影响
- **WHEN** 管理员选中普通答卷
- **THEN** 行为与现状完全一致（评分留空待填）

#### Scenario: 保留人工修改能力
- **WHEN** 管理员修改作弊答卷的预填分数或评语
- **THEN** 以修改后的值提交
