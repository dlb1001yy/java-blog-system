# 部署操作文档 Spec

## Why

用户在 Ubuntu 虚拟机上部署博客系统时遇到了镜像拉取慢、apt-get 超时、Maven 下载卡住等问题。现有文档分散在 README.md 的「Docker 部署」章节和「Docker环境安装指南.md」中，缺少一份专注于「从零到访问验证」的完整操作手册。需要生成一份详细的部署操作文档，涵盖镜像拉取策略、容器启动流程、访问测试步骤，并整合实际部署中遇到的问题与解决方案。

## What Changes

- **新增** 根目录 `部署操作手册.md`，包含以下完整内容：
  - 部署前准备（确认 Docker 已安装、代码已克隆、目录结构检查）
  - Docker 镜像加速器配置（含阿里云专属加速器获取方法）
  - 基础镜像预拉取（按依赖顺序列出所有需拉取的镜像，含镜像大小参考）
  - 后端构建说明（多阶段构建流程、阿里云 Maven 镜像配置说明）
  - 一键启动全部服务（docker compose up 命令、启动顺序说明、启动进度查看）
  - 逐服务状态检查（docker compose ps、健康检查说明、各服务日志查看）
  - 访问测试（前台门户、管理后台、后端 API、接口文档的逐项验证步骤）
  - 常见部署问题排查（基于实际遇到的问题：镜像拉取 429、apt-get 超时、Maven 下载慢、端口冲突、数据库连接失败、前端空白页等）
  - 停止与重新部署（停止、清理、更新代码后重新构建的完整流程）
- **修改** 根目录 `README.md`，在 Docker 部署章节添加指向 `部署操作手册.md` 的链接

## Impact

- Affected specs: `deploy-with-docker-compose`、`create-docker-install-guide`（新文档作为这两者的操作补充）
- Affected code:
  - `部署操作手册.md`（新建）
  - `README.md`（修改，添加链接）

## ADDED Requirements

### Requirement: 部署操作手册文档

系统 SHALL 在项目根目录提供 `部署操作手册.md`，涵盖从镜像拉取到访问测试的完整部署流程，包含镜像加速配置、按依赖顺序的镜像预拉取、一键启动命令、逐服务状态检查、访问测试验证步骤、常见问题排查（含实际遇到的 429/超时等问题解决方案），所有命令可直接复制执行。

#### Scenario: 用户从零部署博客系统
- **WHEN** 用户按照 `部署操作手册.md` 逐步执行
- **THEN** 能够成功拉取镜像、构建并启动全部服务，通过浏览器访问前台门户与管理后台

#### Scenario: 用户遇到镜像拉取问题
- **WHEN** 用户在拉取镜像时遇到 429 或超时
- **THEN** 按照文档「常见部署问题排查」的镜像拉取条目配置阿里云专属加速器后解决

### Requirement: README.md 添加文档链接

系统 SHALL 在 README.md 的 Docker 部署章节添加指向 `部署操作手册.md` 的超链接。
