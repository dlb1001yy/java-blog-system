# 项目文档整合输出 Spec

## Why

`D:\学习资料\study-notes\项目笔记\智谱生成的项目` 目录下有 10 个分散的 Markdown 文档，记录了 Java 博客系统从架构设计、数据库设计、后端代码、前端代码、管理后台代码、移动端 APP 代码到问题修复的完整开发过程。这些文档需要整合为一个有序的单一文件，方便查阅和归档。

## What Changes

- **新增** 根目录 `项目开发文档合集.md`，按逻辑顺序整合以下 10 个源文档：
  1. 项目架构总览与数据库设计（源：具体生成代码.md）
  2. 开发环境搭建与项目初始化实操（源：项目操作实操.md）
  3. 后端代码：启动类、配置、实体、Mapper、Service、Security（源：项目后端代码.md）
  4. 后端代码补充：工具类 JwtUtils/RedisUtils/FileUtils（源：项目后端代码补充.md）
  5. 后端问题修复：BCrypt 密码、事务注解（源：项目后端问题修改.md）
  6. 前台门户代码：组件、视图、API、路由（源：项目后端页面.md）
  7. 管理后台代码：布局、路由、视图、状态管理（源：项目后端管理页面.md）
  8. 管理后台补充：layout 更新、缺失组件（源：项目后端管理页面(补充).md）
  9. 移动端 APP 优化重构版（源：移动端 APP (uni-app) 优化重构版.md）
  10. 移动端 APP 问题修复（源：移动端APP问题修改.md）

## Impact

- Affected code: `项目开发文档合集.md`（新建，根目录）

## ADDED Requirements

### Requirement: 项目开发文档合集

系统 SHALL 在项目根目录生成 `项目开发文档合集.md`，将 10 个源文档按「架构→实操→后端→后端补充→后端修复→前台→后台→后台补充→移动端→移动端修复」的逻辑顺序整合为单一文件，每个源文档作为一级章节，保留原始代码块和格式，文件头部包含目录导航。

#### Scenario: 用户查阅项目开发文档
- **WHEN** 用户打开 `项目开发文档合集.md`
- **THEN** 能够通过目录导航快速跳转到任意章节，查看完整的代码和说明
