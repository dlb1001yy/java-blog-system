# 题目导入模板选项与答案简化填写 Spec

## Why
题目导入模板中"选项(options, JSON数组)"与"正确答案(correct, JSON)"要求手写 JSON 格式，对不懂 JSON 的用户太困难；且用户不清楚哪些题型需要填写选项，正确答案也没有按题型校验。应按题型提供直观填写方式并严格校验。

## What Changes
- 模板"选项"列填写方式简化：仅单选题/多选题需要填写（判断/填空/简答/编程题留空）；多个选项之间用竖线 `|` 分隔的纯文本（如 `final|finally|finalize|const`）。
- 模板"正确答案"列填写方式简化（按题型）：
  - 单选题：填单个字母 `A`
  - 多选题：填多个字母 `AB` 或 `A,B`
  - 判断题：填 `对` 或 `错`（兼容 `正确/错误`、`true/false`、`√/×`）
  - 填空题：多个空用 `|` 分隔
  - 简答/编程题：留空（参考答案填在"参考答案/解析"列）
- **按题型严格校验正确答案**（不能随便填写）：
  - 单选题：必须为单个字母且在选项数量范围内（如 4 个选项只允许 A-D）
  - 多选题：必须为 ≥1 个不重复字母，均不超出选项数量
  - 判断题：必须为对/错（含兼容写法），其他值报错
  - 填空题：必须与题干中空位（如 `____`）数量匹配或至少 1 个非空答案
  - 简答/编程题：必须留空（若填写则报错提示填写到参考答案列）
  - 客观题（1-4）正确答案必填，缺失报错
- 后端导入解析（`ExamQuestionServiceImpl`）：简化写法转换为现有 JSON 存储——选项转 JSON 数组；正确答案转索引格式（单选 `[0]`、多选 `[0,2]`、判断 `[true]/[false]`、填空 `["答案1","答案2"]`）。
- 兼容：以 `[` 开头仍按原 JSON 校验与存储，老文件不破坏。
- 模板表头说明明确题型适用范围：`选项(仅单选题/多选题填写，多个选项用|分隔)`、`正确答案(单选填A，多选填AB，判断题填对或错，填空题多个空用|分隔，简答/编程题留空)`；示例行改用简化写法；前端导入对话框提示文案同步。

## Impact
- Affected code:
  - `blog-backend/.../controller/admin/AdminExamQuestionController.java`（表头与示例）
  - `blog-backend/.../service/impl/ExamQuestionServiceImpl.java`（解析与校验）
  - `blog-admin/src/views/ExamQuestionList.vue`（导入对话框提示文案）
- 修改 spec：use-type-name-in-import-template（模板列说明与示例）

## ADDED Requirements
### Requirement: 选项与正确答案按题型简化填写并严格校验
系统 SHALL 在模板说明与导入提示中明确选项/答案各题型的填写要求，导入时按题型严格校验正确答案合法性，并接受纯文本形式转换为内部 JSON。

#### Scenario: 单选题简化填写
- **WHEN** 题型为"单选题"，选项 `final|finally|finalize|const`，正确答案 `A`
- **THEN** 导入成功，options 存为 JSON 数组，correct 存为 `[0]`

#### Scenario: 单选题答案非法
- **WHEN** 题型为"单选题"，正确答案为 `AB` 或 `E`（超出选项范围）或为空
- **THEN** 该行报错（如"单选题正确答案必须为单个选项字母（A-D）"）且不落库

#### Scenario: 多选题答案非法
- **WHEN** 题型为"多选题"，正确答案 `AA` 或字母越界
- **THEN** 该行报错"多选题正确答案必须为不重复的选项字母"且不落库

#### Scenario: 判断题答案非法
- **WHEN** 题型为"判断题"，正确答案为 `C` 或其他非法值
- **THEN** 该行报错"判断题正确答案必须为：对/错"且不落库

#### Scenario: 简答题填写了答案列
- **WHEN** 题型为"简答题"，正确答案列填写了内容
- **THEN** 该行报错提示"简答/编程题无需填写正确答案，请填参考答案列"且不落库

#### Scenario: 兼容原有 JSON
- **WHEN** 选项/正确答案以 `[` 开头
- **THEN** 按原 JSON 格式校验与存储，行为不变
