# 三端视觉统一变更摘要

> 变更 ID：`unify-brand-style-across-clients`（令牌级统一）+ `unify-visual-language-across-clients`（深度视觉统一）
> 范围：blog-admin / blog-frontend / blog-app
> 状态：已完成，双端生产构建通过，检查项全部勾选；代码审查后追加修复 21 处 rgba 旧色残留并同步文档

## 一、背景

三端视觉割裂严重：

| 问题 | 之前 | 之后 |
|---|---|---|
| 主色 | admin 翡翠绿 #059669 / frontend Element 蓝 #409eff / app 靛蓝 #4F46E5 | 统一翡翠绿体系 |
| 站名 | "Java 博客" 与 "Java码农笔记" 并存 | 统一 "Java码农笔记" |
| Logo | 四种来源互不相同（紫闪电/蓝渐变/无品牌） | 统一翡翠绿渐变咖啡杯 + `{ }` |
| 圆角 | app 4/8/12/16，web 8/12/16/20 | 统一 8/12/16/20 阶梯 |
| 阴影/反馈/空态 | 三端各自为政 | 统一刻度与规范 |

## 二、统一后的品牌基准

| 令牌 | 值 |
|---|---|
| primary | `#059669` |
| primary-light / primary-dark | `#10B981` / `#047857` |
| secondary / accent | `#0D9488` / `#14B8A6` |
| 渐变 | `linear-gradient(135deg, #059669 0%, #14B8A6 100%)` |
| 圆角 sm/md/lg/xl | `8 / 12 / 16 / 20px` |
| 暗色 bg / card | `#0B0F0E` / `#131A18`（暗色主色 `#34D399`） |
| 字体栈 | `'Inter', 'Plus Jakarta Sans', -apple-system, ...` |
| 过渡时长 | fast `0.15s` / base `0.25s` |
| 阴影基色 | slate（`rgba(15,23,42,*)`） |

基准源自 `blog-admin/src/assets/styles/tokens.css`，admin 作为基准端令牌零改动。

## 三、变更明细

### 1. 令牌级统一（第一轮）

**blog-frontend**
- `global.css`：主色/圆角/字体栈对齐 admin；补齐 Element Plus 阶梯 `--el-color-primary-light-3~9 / dark-2`；阴影改 slate 基；补 `--container-padding`
- 清理硬编码旧蓝：LogoIcon、Home、Upload、ExamTaking 及 AppHeader/BackToTop/AboutSite/Interview/PlayerBar/Music/Scores 等共 11 个文件

**blog-app**
- `common/theme.js`：colors / darkColors 全套切绿色基准（暗色主色 `#34D399`）
- `uni.scss`：11 个 `$color-*` 令牌替换；圆角升级 `4/8/12/16 → 8/12/16/20`
- `App.vue`：`--app-*` 亮暗 CSS 变量全套替换
- `theme.json`：导航栏配色（light `#059669`、dark `#0B0F0E`）
- 清理 31 个文件的靛蓝系硬编码 fallback

**blog-admin**：零改动（基准端）。

### 2. 品牌资产统一（第二轮）

- `blog-admin/public/favicon.svg`：紫闪电 → 翡翠绿渐变咖啡杯 + `{ }`
- `blog-admin/public/icons.svg`：5 处 `#aa3bff` → `#10B981`
- `blog-frontend/public/favicon.svg`：蓝渐变 → `#059669→#14B8A6`
- `blog-app/static/logo.png`：GDI+ 重绘 192px 同款咖啡杯
- 站名统一：`blog-admin/src/layout/index.vue`、`views/Login.vue`、`index.html`（title：Java码农笔记后台管理）
- app 首页 Hero 新增 `.hero-brand` 品牌露出（48px logo + 站名）

### 3. 视觉冲突清理（frontend）

- `Home.vue`：Hero 紫渐变（`#667eea/#764ba2`）→ `#047857→#0D9488`；模块图标配色改 `#059669/#0D9488/#14B8A6/#2DD4BF` + `rgba(*,0.1)` 背景
- `LatestBlogCard.vue`：`#9b59b6` → `#14B8A6`；hover 阴影改 `var(--shadow-hover)`
- `ArticleDetail.vue`：阅读进度条紫渐变 → 品牌渐变
- `Music/PlayerBar`：占位封面 `#9b59b6` 清理
- `SkeletonCard.vue`：底色 `#e8ebf0` → `var(--border-color)`

### 4. 样式收敛（admin）

- `global.css` 全局定义表格行 hover（主色 light-9 浅底 + 0.25s 过渡），删除 **15 个视图**的重复 `:deep` 块（ArticleList/UserList/CommentList/BackupManage/MessageList/LinkList/OperationLogList/CategoryList/ExamPaperList/ExamQuestionList/InterviewQuestionList/MusicManage/TagList/ResumeManage/TaskManage）
- 删除死代码：零使用的 `.hover-lift`、与 scoped 冲突的 `.slide-fade` 纵向定义
- `el-empty` image-size 60 → 80（Dashboard、ExamPaperList×2）

### 5. 交互反馈统一

- web 端可交互卡片：hover `translateY(-4px)` + `--shadow-hover`
- app 按压：`scale(0.98)` + `opacity: 0.9`，`transition: 0.15s`（module-item、latest-item 对齐 ArticleItem 规范）
- app 游离圆角清理：`latest-item 10px → $radius-md`、`stats-card/modules 14px → $radius-lg`

### 6. 空态反馈补齐（app）

首页"最新文章"由静默隐藏改为四分支：骨架屏 → 失败空态 + 重试按钮 → 暂无文章 → 列表。

### 7. 审查后追加修复（code review 轮）

**blog-app 21 处旧色 rgba() 残留（10 个文件）**
- 原因：hex 替换覆盖了 `#4F46E5` 等字符串形式，但同一颜色的 rgba 函数形式漏改，形成"绿字紫底"混色（题型 tag、选中选项、渐变按钮投影、成绩图表等）
- 修复映射（透明度原样保留）：
  | 旧值 | 新值 | 对应色 |
  |---|---|---|
  | `rgba(79,70,229,x)` | `rgba(5,150,105,x)` | #4F46E5 → #059669 |
  | `rgba(129,140,248,x)` | `rgba(52,211,153,x)` | #818CF8 → #34D399 |
  | `rgba(6,182,212,x)` | `rgba(13,148,136,x)` | #06B6D4 → #0D9488 |
  | `rgba(139,92,246,x)` | `rgba(20,184,166,x)` | #8B5CF6 → #14B8A6 |
- 涉及：article/detail、study/scores、study/exam/taking、subpkg/resume、subpkg/about、subpkg/message、subpkg/mine（index/login/register）、study/interview

**blog-app/README.md 令牌段同步**
- 设计令牌示例与 `theme.js` 实际对齐（含 spacing/radii/shadows 键名与值）
- 开发约定表格配色更新为 `主色 #059669，辅色 #0D9488`
- TabBar 颜色描述更新为 `默认 #A8A29E，激活 #059669（--app-primary）`

## 四、顺带修复的 Bug
