# 首页简化：只展示最新文章

## Summary

首页（`blog-app/pages/index/index.vue`）移除"最新文章"区块下方的搜索栏、分类筛选 chips 和完整文章列表（含分页/触底加载/离线缓存列表），页面只保留：Hero → 统计卡 → 功能模块入口 → 最新文章（3 篇，"查看全部"跳转文章列表页）。浏览完整文章列表的入口全部收敛到 `/subpkg-article/pages/list`。

## Current State Analysis

现状（[index.vue](d:/my-project/java-blog-system/blog-app/pages/index/index.vue)）：

- 页面区块顺序：Hero → 统计卡 → 功能模块 → **最新文章区（3 篇，`loadLatest()` 调 `api.getLatestArticles()`，失败静默隐藏）** → 搜索栏 → 搜索结果数/分类 chips → **文章列表（`fetchData()` 分页 + `onLoadMore` 触底加载 + `onRefresh` 下拉刷新 + 离线缓存 `cacheArticleList`/`getCachedArticleList`）**
- 与列表相关的状态：`list/page/hasMore/fetchSeq/searchKeyword/isSearching/searchTotal/activeCategoryId/activeType/categories/searchSkeleton` 等
- 列表相关依赖组件：`ArticleItem`、`SearchBar`、`CategoryChips`、`Skeleton`（列表骨架）、`LoadingDots`（加载更多动画）
- 最新文章区自身仅依赖 `Skeleton`（loading 骨架）、`Icon`、`api.getLatestArticles`
- `offlineMode`/`initNetworkWatch` 除列表外还被 `loadQuestionCount`、`loadLatest` 使用，需保留
- 分类列表 `loadCategories()` 仅为 chips 服务，可一并移除

## Proposed Changes

只改一个文件：[pages/index/index.vue](d:/my-project/java-blog-system/blog-app/pages/index/index.vue)

### 1. 模板部分

- 删除「搜索栏」区块（`.search-wrap` + `SearchBar`，L98-106）
- 删除「搜索结果数」区块（`.search-info`，L108-111）
- 删除「分类筛选 chips」区块（`.chips-wrap` + 两个 `CategoryChips`，L113-117）
- 删除「文章列表」区块（`.list`：Skeleton、`ArticleItem` 循环、空状态、加载更多/没有更多，L119-147）
- 最新文章区（L61-96）原样保留
- 保留：scroll-view 下拉刷新（刷新统计/题量/最新文章）、Hero、统计卡、功能模块、PlayerBar、TabBar

### 2. 脚本部分

删除仅服务列表/搜索/筛选的代码：

- import：`ArticleItem`、`SearchBar`、`CategoryChips`、`LoadingDots`；`common/offline.js` 中的 `cacheArticleList`、`getCachedArticleList`（保留 `initNetworkWatch`、`offlineMode`）
- 状态：`list`、`page`、`hasMore`、`fetchSeq`、`showSkeleton`、`searchKeyword`、`isSearching`、`searchTotal`、`activeCategoryId`、`activeType`、`categories`、`categoryChips`、`loading`
- 方法：`fetchData`、`onSearchInput`、`onSearch`、`exitSearch`、`onCategoryChange`、`onTypeChange`、`loadCategories`、`onLoadMore`
- `types` 常量（类型 chips 固定列表）
- `onLoad()` 中移除 `fetchData()` 调用（保留 `initNetworkWatch/loadStats/loadQuestionCount/loadLatest`）
- `onRefresh()` 中移除 `page/hasMore/list` 重置与 `fetchData()`（保留统计/题量/最新文章刷新）

保留：`refresherStyle`、`refreshing`、`stats`、`questionCount`、最新文章相关（`latestLoading/latestFailed/latestArticles/showLatestSection/loadLatest/latestCover`）、`formatCount`、`statsText`、`statItems`、`goDetail`、`goArticleList`、`goModule`、`onShow`/`watch(isDark)`

### 3. 样式部分

删除仅服务已移除区块的样式：`.search-wrap`（含 `:deep(.search-bar)`）、`.search-info`、`.search-info-text`、`.chips-wrap`、`.list`、`.empty`、`.empty-icon`、`.empty-text`、`.status`

保留其余全部样式（Hero/统计卡/模块/最新文章/刷新动画）。

注：`Skeleton` 组件仍被最新文章 loading 使用，import 保留；`ArticleItem.vue` 等组件文件本身不动（文章列表页 `subpkg-article/pages/list` 仍在使用）。

## Assumptions & Decisions

- 最新文章数量保持 3 篇（接口 `getLatestArticles()` 返回后 `slice(0, 3)`，现状不变）
- 下拉刷新保留，刷新对象收敛为统计/题量/最新文章
- 离线模式下最新文章区仍按现状静默隐藏（`latestFailed = true`）
- 不修改 `pages.json`、路由、API 层与任何子包页面
