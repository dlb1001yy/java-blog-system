# 登录页添加图形验证码

## 摘要
后端登录已强制校验图形验证码（`captcha-enabled: true`，`GET /auth/captcha` 返回 `{ captchaId, image }`，Redis 存 60 秒），但前端登录页没有验证码输入框，导致登录总报"验证码错误或已过期"。需在前端补齐验证码 UI 与请求参数。

## 现状分析
- 后端 `AuthController#login` 要求 `LoginRequest { username, password, captchaId, captchaCode }`，验证失败返回 400 "验证码错误或已过期"。
- 验证码接口：`GET /auth/captcha`（SecurityConfig 已放行 `/auth/**`），返回 `captchaId` + `image`（Base64 data URI，Hutool LineCaptcha 130x40）。验证为一次性消费（getAndDelete），过期 60 秒。
- 前端 [Login.vue](file:///d:/my-project/java-blog-system/blog-frontend/src/views/Login.vue) 只有用户名/密码；[auth.js](file:///d:/my-project/java-blog-system/blog-frontend/src/api/auth.js) 无验证码接口。
- 拦截器（request.js）已统一弹错，登录失败会提示后端消息。

## 修改方案（仅前端，2 个文件）

### 1. `blog-frontend/src/api/auth.js`
新增：
```js
// 获取图形验证码
getCaptcha() {
  return request.get('/auth/captcha')
}
```

### 2. `blog-frontend/src/views/Login.vue`
- **表单新增验证码项**（密码项之后）：
  ```html
  <el-form-item prop="captchaCode">
    <div class="captcha-row">
      <el-input v-model="form.captchaCode" placeholder="验证码" :prefix-icon="Key"
        @keyup.enter="handleLogin" />
      <img v-if="captcha.image" :src="captcha.image" class="captcha-img" title="点击刷新" @click="loadCaptcha" />
    </div>
  </el-form-item>
  ```
- **script**：
  - `captcha = reactive({ captchaId: '', image: '' })`；`form` 增加 `captchaCode: ''`。
  - rules 增加 `captchaCode: [{ required: true, message: '请输入验证码', trigger: 'blur' }]`。
  - `loadCaptcha()`：调用 `authApi.getCaptcha()`，`captcha.captchaId = res.data.captchaId`、`captcha.image = res.data.image`（image 已是 data URI，直接绑定）；`onMounted` 时调用。
  - `handleLogin()`：提交 `{ ...form, captchaId: captcha.captchaId, captchaCode: form.captchaCode }`；无论成功失败，finally 中清空 `form.captchaCode` 并 `loadCaptcha()` 刷新（验证码一次性消费，失败后必须换新）。
- **style**：
  ```css
  .captcha-row { display: flex; gap: 10px; width: 100%; }
  .captcha-row .el-input { flex: 1; }
  .captcha-img { height: 40px; width: 130px; border-radius: 4px; cursor: pointer; border: 1px solid var(--border-color); }
  ```
- 引入 `Key` 图标（@element-plus/icons-vue）。

## 假设与决策
- 仅改前端，后端无需动（验证码功能已完整）。
- 60 秒过期较短：用户停留超 60 秒提交会失败，失败后自动刷新验证码并提示，体验可接受；不做倒计时（避免过度设计）。
- 注册接口后端未校验验证码，Register.vue 不改。

## 验证步骤
1. 启动后端 + 前端（`npm run dev`）。
2. 打开登录页：验证码图片自动加载。
3. 输错验证码登录 → 提示"验证码错误或已过期"，验证码自动刷新、输入清空。
4. 输对验证码 → 登录成功跳转。
5. 点击图片可手动刷新验证码。
